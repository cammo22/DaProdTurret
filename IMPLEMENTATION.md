# Implementation contract — DaProdTurret alpha

Approved: browser-first 3D playable incremental naval turret game; desktop + Android browser and installable PWA, GitHub Pages static export. Not a native APK yet. Italian UI. Local project /home/cammo/Scrivania/DaProdTurret. Node ESM, Three.js, Vite, node:test + Playwright. Relative paths throughout (Pages subdirectory).

## Engine public API (src/engine.js)
Exports WEAPONS, UPGRADES, createGame(now=Date.now()), tick(game,dt), startWave(game), buyUpgrade(game,id), setWeapon(game,id), setPriority(game,id), pulse(game), extract(game), stats(game), serializeGame(game,now=Date.now()), loadGame(json,now=Date.now()). Mutating functions return boolean success except tick and load/create. stats returns {damage,fireRate,maxHp,maxEnergy,energyRegen,range}.
WEAPONS is object keyed cannon/tesla/rail, each {name,description,cost,color}; cannon cost 0, tesla cost 100, rail cost 180; selecting locked weapon attempts to purchase then equip, unlocked free. Colors are hex numbers. UPGRADES object keyed damage/rate/hull/reactor/salvage, each {name,description,baseCost}; expose upgradeCost(game,id). Upgrade levels stored in game.upgrades. Design costs so first upgrade is accessible after wave1 (start scrap 45, damage base35).

Game state: {version:1, phase:'ready'|'combat'|'intermission'|'defeat', wave:0, bestWave:0, scrap:45, research:0, pendingResearch:0, hp:100, energy:100, kills:0, weapon:'cannon', unlocked:['cannon'], priority:'nearest', autoWave:false, upgrades:{damage:0,rate:0,hull:0,reactor:0,salvage:0}, enemies:[], effects:[], time:0, waveKills:0, waveTotal:0, spawnRemaining:0, spawnTimer:0, cooldown:0, pulseCooldown:0, nextId:1, aim:null, lastSavedAt:now, notice:'...'}.
Enemies {id,type:'skiff'|'frigate'|'armored'|'boss',x,z,hp,maxHp,speed,reward,attackCooldown}. World positions sea plane x/z, turret at0/0, enemy spawn radius18-22, reach station at radius3.5. Boss every5th wave. Engine owns deterministic simulation and damage, renderer owns visuals. aim = null or {x,z}; when aim exists auto firing prioritizes nearest enemy to aim, else uses priority. priority nearest/strongest/weakest. No manual-fire requirement; pointer/touch selects focus, and release clears.
Effects short-lived {id,kind:'shot'|'tesla'|'rail'|'explosion'|'pulse', x:sourceX,z:sourceZ, tx:targetX,tz:targetZ, ttl,maxTtl}; tick decays effects. Tracer IDs monotonic. Weapon cooldowns, energy costs; tesla chains, rail pierces. Max enemy count bounded by waves. HP damage at station, rewards per kill exactly once. Intermission when all spawns/enemies cleared, heal some and add pendingResearch. Can click start next wave, autoWave optionally. No game time pass while hidden or paused; offline salvage capped, only bestWave>0. pulse AOE costs energy and has cooldown. Extract banks pending research, resets expedition preserving research,bestWave and returns ready; research modest permanent damage benefit. Defeat restart via extract, no phantom rewards. load validates untrusted save, drops combat transient state, uses safe intermission/ready and clamps gains.

## Ownership
Engine agent only writes src/engine.js, tests/engine.test.js and optional docs/BALANCE.md. Do not edit package or UI.
Frontend agent only writes index.html, src/main.js, src/style.css, optional src/audio.js. Do not edit engine, tests, package/PWA. Parent owns public assets, PWA, docs, CI/deploy and E2E.

## Frontend requirements
Surface: Operate/Monitor, not landing page. Viewport-filling 3D ocean + platform, restrained naval dark aesthetic, amber actionable controls/cyan energy, HUD top, dock/inspector right desktop and bottom mobile. Beautiful stylized procedural models baseline; no dependency on Meshy result. Platform cylindrical metal base, modular gun barrels and energy rings, red/orange enemy hulls with wakes; waves/grid/ocean vertex ripples, hazy horizon, shot particles, hit feedback. Orthographic tilted camera responsive field so enemies remain visible mobile. Render at DPR capped1.5 mobile/2 desktop, no expensive postprocess. Pause/audio/fullscreen/help. Toolbar weapon selection, upgrade purchase (real costs, disabled states), pulse, next wave, extract with confirmation when pendingResearch>0; priorities selector, autoWave toggle; recovery after defeat; save every few seconds and on visibility/pagehide, no UI localStorage crashes. Onboarding overlay with Inizia spedizione, never block continuing save. Controls touch >=44px. No remote fonts/CDNs. Accessible labels, no tiny gray text, no horizontal overflow at390x844, portrait and landscape playable. Keyboard space=pulse, 1/2/3=weapons, P=pause; pointer/touch focus targeting. Reduced motion support. Expose window.__DAPROD__ = { get game(){return game}, ...optional tick/start funcs} for read-only QA plus UI actions. Dynamic new-game reset requires confirmation.

Optional Meshy decoration parent may put public/assets/meshy-platform.glb; don't request if absent. Procedural art must look good regardless.
